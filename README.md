# VS Computer Education

Complete website and management system for VS Computer Education, Surat, Gujarat.

## Tech Stack
- Node.js (Express)
- SQLite (Node 22 built-in)
- HTML/CSS/JS frontend
- JWT Authentication

## Setup

```bash
npm install
npm start
```

Visit http://localhost:3000
